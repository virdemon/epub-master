EPUB Master

EPUB 排版与压缩大师

版本 1.2 本地运行 · 文件不外传 运行环境检测中

作者 virdemon

设计理念

让每个人都能用简单的方式，读到更理想的 EPUB。

我们相信，电子书优化不应该以牺牲阅读体验为代价。EPUB Master 希望通过简单、直观的操作，帮助每位读者更轻松地优化和整理自己的电子书。

我们尤其重视图片的呈现效果。在合理减小书籍体积的同时，尽可能保留图片的清晰度与细节，让每一次翻阅都更加舒适、清晰，也更有沉浸感。

我们坚持按需优化：能够保留的原始排版就尽量保留，需要修复的结构才谨慎调整。图片压缩、字体处理、资源清理等操作都应当尽可能透明，让用户知道书籍发生了什么变化、节省了多少空间，以及哪些内容没有被修改。

让电子书更轻，让图片依然清晰，让阅读回归本身。

核心功能

导入即预览不处理也能翻看原书正文、图片、表格与目录
图片浏览与对比缩略图网格看全部图片，可对同一张图比较压缩前后
三档压缩标准保真 / 深度优化 / 极致压缩，差异体现在真实参数上
结构诊断与修复manifest 双向校验、死引用、大小写、XML 良构
可选分卷超大部头按章节边界拆卷，每卷都能独立打开
EPUB 2 / 3 输出按目标版本重建包结构，并核对是否真的符合

运行环境与依赖

桌面版Electron 外壳，界面与处理逻辑和网页版完全同一份代码
压缩引擎fflate（解包） + 浏览器原生 CompressionStream（打包，比 JS deflate 更小）
图像处理Canvas 2D 重编码为 JPEG，GIF / SVG 一律跳过以免破坏动图与矢量
数据存储仅本机：localStorage 存设置与历史，IndexedDB 存输出目录句柄
网络处理过程不发起任何网络请求
